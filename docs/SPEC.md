## 2. ขอบเขต MVP

### 2.1 ฝั่งลูกค้า (หน้าร้าน)
- **หน้าแรก**: แบนเนอร์โปร (สไลด์), แถบหมวดหมู่, Flash sale พร้อมนับถอยหลัง, สินค้าแนะนำ/ขายดี
- **หมวดหมู่ + ค้นหา**: หมวดซ้อนได้ 2 ชั้น, ค้นหาภาษาไทย/อังกฤษ (พิมพ์ผิดนิดหน่อยก็เจอ), ตัวกรองราคา/หมวด/คะแนน, เรียงลำดับ
- **หน้าสินค้า**: รูปหลายรูป (ซูม/ปัด), ตัวเลือกสินค้า (สี/ไซซ์ → แต่ละตัวเลือกมี SKU, ราคา, สต็อกของตัวเอง), รีวิว, สินค้าที่เกี่ยวข้อง
- **ตะกร้า + ชำระเงิน**: ตะกร้าเก็บได้ทั้งตอนยังไม่ล็อกอินและหลังล็อกอิน (รวมกันอัตโนมัติ), ใส่คูปอง, เลือกที่อยู่, คำนวณค่าส่ง, จ่ายด้วย PromptPay QR หรือบัตร
- **บัญชีผู้ใช้**: สมัคร/ล็อกอินด้วยอีเมล หรือ Google, สมุดที่อยู่, ประวัติคำสั่งซื้อ, ติดตามพัสดุ, รายการโปรด (wishlist)
- **รีวิว**: ให้ดาว + ข้อความ + รูป ได้เฉพาะคนที่ได้รับสินค้าแล้ว
- **แชทกับร้าน**: แชทแบบ real-time จากหน้าสินค้า/คำสั่งซื้อ, แนบรูปได้, แจ้งเตือนเมื่อมีข้อความใหม่
- **PWA**: ติดตั้งลงหน้าจอมือถือได้, โหลดเร็ว

### 2.2 ฝั่งร้าน/แอดมิน (หลังร้าน)
- **Dashboard**: ยอดขายวันนี้/เดือนนี้, คำสั่งซื้อรอจัดการ, สินค้าใกล้หมด
- **จัดการสินค้า**: เพิ่ม/แก้/ซ่อน, ตัวเลือกสินค้า, อัปโหลดรูป, **นำเข้า/ส่งออก CSV** (เพราะมีหลักร้อยถึงพันรายการ)
- **จัดการคำสั่งซื้อ**: สถานะ (รอชำระ → ชำระแล้ว → แพ็ค → ส่งแล้ว → สำเร็จ / ยกเลิก / คืนเงิน), กด "สร้างใบส่ง Flash" → ได้เลขพัสดุ + พิมพ์ใบปะหน้า, สถานะอัปเดตเองจาก Flash
- **โปรโมชัน**: คูปอง (ลด % / ลดบาท / ส่งฟรี, ยอดขั้นต่ำ, จำกัดจำนวนครั้ง, วันหมดอายุ), Flash sale (ช่วงเวลา, ราคาพิเศษ, จำกัดจำนวนชิ้น)
- **แชท**: กล่องข้อความรวม ตอบลูกค้าได้หลายคน
- **รีวิว**: ซ่อนรีวิวที่ไม่เหมาะสม, ตอบกลับรีวิว
- **ผู้ใช้หลังร้าน + สิทธิ์ (RBAC)**: Owner / Admin / Staff (แพ็คของ, ตอบแชท) — แต่ละบทบาทเห็นเฉพาะที่จำเป็น
- **แบนเนอร์หน้าแรก**: เปลี่ยนรูป/ลิงก์โปรเองได้ ไม่ต้องเรียกโปรแกรมเมอร์

### 2.3 Responsive + Animation + SEO (บอสสั่งเพิ่ม — ทุกหน้าต้องผ่าน)
- **Responsive ทุกจอ**: มือถือ (iPhone SE 375px ขึ้นไป, Android), มือถือจอพับ/จอคู่ (iPhone Duo/foldable — layout ปรับตามจอที่กางหรือพับ), **iPad / แท็บเล็ต** ทั้งแนวตั้งและแนวนอน, โน้ตบุ๊ก, จอใหญ่
  - มือถือ: แถบเมนูล่าง (หน้าแรก/หมวด/ตะกร้า/บัญชี), ปุ่มใหญ่กดง่าย, ปัดรูปสินค้า, ตะกร้าลอย
  - iPad/แท็บเล็ต: grid สินค้า 3–4 คอลัมน์, หลังร้านใช้งานบน iPad ได้เต็มที่ (แพ็คของหน้างาน)
  - ทุกปุ่ม/ลิงก์มี cursor-pointer และ hover/press state, ไม่มี scroll แนวนอนหลุด
- **Animation สวยระดับ Apple** (ลื่น ไม่รก ไม่ทำให้ช้า): เปิดหน้าแบบ fade/slide นุ่มๆ, สินค้าเลื่อนขึ้นตอน scroll, ปุ่ม "ใส่ตะกร้า" มีของบินเข้าตะกร้า, นับถอยหลัง flash sale แบบตัวเลขพลิก, skeleton ตอนโหลด, แบนเนอร์สไลด์ลื่น; เคารพการตั้งค่า "ลดการเคลื่อนไหว" ของเครื่อง; ใช้ Framer Motion (Motion) + CSS transitions, รักษา 60fps บนมือถือ
- **SEO เต็มรูปแบบ**: หน้าสินค้า/หมวดเป็น SSR/ISR, title/description เฉพาะแต่ละหน้า, Open Graph สำหรับแชร์ LINE/Facebook, structured data (Product, Offer, AggregateRating, Review, BreadcrumbList, Organization), sitemap.xml + robots.txt อัตโนมัติ, canonical URL, URL อ่านง่าย, รูปมี alt + ย่อขนาดอัตโนมัติ, Core Web Vitals ผ่านเกณฑ์ (LCP < 2.5s บนมือถือ), เชื่อม Google Search Console + GA4

### 2.4 ไม่อยู่ใน MVP (ย้ายไปเฟสถัดไป)
- เก็บเงินปลายทาง (COD) · ขนส่งเจ้าอื่น (Kerry, J&T, ไปรษณีย์ไทย)
- แต้มสะสม / Coins / แนะนำเพื่อน · ระบบ affiliate
- Live / วิดีโอสินค้า · แอป iOS/Android จริง
- Multi-vendor (ให้คนอื่นมาเปิดร้าน) · หลายภาษา (MVP เป็นภาษาไทย)
- ระบบคลัง/หลายคลัง, เชื่อม ERP · ออกใบกำกับภาษีเต็มรูปอัตโนมัติ (MVP ออกใบเสร็จ PDF ได้)

## 3. สถาปัตยกรรม

ใช้ stack เดียวกับ ecomacrobiz.com เพื่อให้ทีมทำงานเร็วและดูแลง่าย

```
ลูกค้า / แอดมิน (มือถือ, iPad, คอม)
          │
   Next.js 16 + TypeScript + Tailwind 4   ← หน้าร้าน (SSR/ISR เพื่อ SEO) + หลังร้าน /admin
          │  REST (JSON) + WebSocket (แชท)
   Go 1.25 + Gin API
     ├─ Postgres (Railway SG)       ← สินค้า, คำสั่งซื้อ, ผู้ใช้, คูปอง, รีวิว, แชท
     ├─ Object storage (Cloudflare R2) + CDN ← รูปสินค้า/รีวิว/แชท (ย่อรูปอัตโนมัติ)
     ├─ Omise                       ← PromptPay QR + บัตร (webhook ยืนยันการจ่าย)
     ├─ Flash Express Open API      ← ค่าส่ง, สร้างใบส่ง, ใบปะหน้า, สถานะพัสดุ
     └─ Email (Resend หรือ AWS SES) ← ยืนยันคำสั่งซื้อ, ลืมรหัสผ่าน, แจ้งส่งของ
```

**การเลือกที่สำคัญ (และเหตุผล)**
- **Omise เจ้าเดียวทำทั้ง PromptPay + บัตร** — สัญญาเดียว, หน้าจ่ายบัตรใช้ Omise.js (ข้อมูลบัตรไม่ผ่านเซิร์ฟเวอร์เรา → ภาระ PCI ต่ำสุด). 2C2P/Stripe TH ใช้แทนได้ถ้าบอสมีบัญชีอยู่แล้ว — โค้ดจะแยกชั้น payment ไว้ให้เปลี่ยนเจ้าได้
- **Flash sale กันขายเกินสต็อก** — ตัดสต็อกแบบ atomic ใน Postgres (`UPDATE ... WHERE stock >= qty`) + จองสต็อกตอนเริ่มจ่าย 15 นาที ถ้าไม่จ่ายคืนสต็อกอัตโนมัติ. ร้านเดียวขนาดนี้ยังไม่ต้องใช้ Redis
- **ค้นหาภาษาไทย** — Postgres `pg_trgm` (ภาษาไทยไม่มีเว้นวรรค full-text ปกติใช้ไม่ดี) เพียงพอสำหรับ ≤1,000 รายการ; ถ้าโตค่อยย้ายไป Meilisearch
- **แชท** — WebSocket ใน Go API ตัวเดียวกัน เก็บข้อความใน Postgres; ถ้าหลุดก็โหลดย้อนหลังได้
- **ความปลอดภัย** — รหัสผ่าน argon2id, Google sign-in, RBAC, เข้ารหัสข้อมูลส่วนบุคคลที่ sensitive (เบอร์โทร/ที่อยู่) at rest, rate limit, ตรวจลายเซ็น webhook ของ Omise/Flash, audit log ฝั่งแอดมิน
- **SEO** — หน้าสินค้า/หมวดเป็น SSR, structured data (Product, Offer, Review, Breadcrumb), sitemap อัตโนมัติ, URL ภาษาไทยอ่านง่าย, รูป next/image
- **Deploy** — GitHub repo ของบอส, branch `Develop` → PR → `main` deploy ขึ้น Railway (Singapore) ผ่าน Dockerfile เหมือนเดิม; มี environment staging แยก (Omise test mode, Flash sandbox)

### ตารางหลักในฐานข้อมูล (ร่าง)
`users`, `addresses`, `staff_roles` · `categories`, `products`, `product_variants`, `product_images` · `carts`, `cart_items` · `orders`, `order_items`, `payments`, `shipments`, `shipment_events` · `coupons`, `coupon_redemptions`, `flash_sales`, `flash_sale_items`, `stock_reservations` · `reviews`, `review_images` · `chat_threads`, `chat_messages` · `banners`, `audit_logs`

## 5. สิ่งที่บอสต้องเตรียม (ใช้เวลารออนุมัติ — ควรเริ่มเลย)

1. **บัญชี Omise (merchant)** — ต้องใช้เอกสารบริษัท/ร้าน, บัญชีธนาคาร; อนุมัติใช้เวลาหลายวันถึงหลายสัปดาห์ (ระหว่างนี้ทีมใช้ test mode ได้)
2. **บัญชีธุรกิจ Flash Express + ขอ Open API key** — ติดต่อฝ่ายขาย Flash
3. **โดเมน** — เช่น `shopship.co.th` (ต้องใช้เอกสารนิติบุคคล) หรือ `.com`; ควรเช็ก/จดเครื่องหมายการค้า "ShopShip" ด้วย
4. **จดทะเบียนพาณิชย์อิเล็กทรอนิกส์** กับกรมพัฒนาธุรกิจการค้า + เครื่องหมาย DBD Registered
5. **สินค้าจริง** — ไฟล์ CSV/รูปสินค้า ภายในสัปดาห์ที่ 10

## 6. ต้องผ่านฝ่ายกฎหมายก่อนเปิดตัว (Praewa ตรวจ — ไม่ใช่ความเห็นทนายที่มีใบอนุญาต)
- Privacy Policy + การขอความยินยอมตาม **PDPA** (คุกกี้, การตลาด, เก็บที่อยู่/เบอร์), ช่องทางลบบัญชี/ขอข้อมูล
- ข้อกำหนดการใช้งาน, **นโยบายคืนสินค้า/คืนเงิน** ตามกฎหมายคุ้มครองผู้บริโภค
- เงื่อนไขคูปองและ Flash sale (ราคาอ้างอิง "ลดจาก" ต้องเป็นราคาจริง)
- VAT / ใบเสร็จ / ภาษี e-commerce
- ข้อความรีวิว (ห้ามรีวิวปลอม), การโฆษณาสินค้าที่มีกฎเฉพาะ (อาหาร, เครื่องสำอาง, อาหารเสริม ฯลฯ)

## 7. ค่าใช้จ่ายรายเดือนโดยประมาณ (ช่วงแรก — ตัวเลขคร่าวๆ ต้องเช็กราคาปัจจุบัน)
- Railway (API + เว็บ + Postgres, staging + production): ~US$30–80
- Cloudflare R2 + CDN: ~US$0–10
- อีเมล: ฟรี–US$20
- โดเมน: ~฿500–1,000/ปี
- ค่าธรรมเนียม Omise: คิดเป็น % ต่อรายการ (บัตรสูงกว่า PromptPay) — ยืนยันเรทตอนเซ็นสัญญา
- ค่าส่ง Flash: ตามเรทสัญญา

## 8. นิยามว่า MVP "เสร็จ"
- ลูกค้าบนมือถือ/iPad/คอม ค้นหา → ใส่ตะกร้า → ใช้คูปอง → จ่าย PromptPay หรือบัตร → ได้อีเมลยืนยัน → เห็นเลขพัสดุ Flash และสถานะอัปเดตเอง
- แอดมินเพิ่มสินค้า (รวม CSV), จัดคูปอง/Flash sale, ออกใบส่ง, ตอบแชท, ดูยอดขายได้เองโดยไม่ต้องพึ่งโปรแกรมเมอร์
- Flash sale 500 คนกดพร้อมกันไม่ขายเกินสต็อก (load test ผ่าน)
- Lighthouse มือถือ ≥ 90 (Performance/SEO/Accessibility), ผ่าน security review, เอกสารกฎหมายผ่านการตรวจ
